SQD rescue

Give the noisy chip a different job: point at the electron arrangements that matter, then solve exactly inside them on a normal computer. The fair test is a fixed budget: does the chip pick better arrangements than chance?

About 30–60 s for the 11-qubit space.

Read this before quoting a number

Each method may solve exactly only inside the arrangements built from its top picks. Without a budget, enough random bitstrings eventually cover a space this small, so the real payoff is in spaces too large to enumerate (IBM ran SQD on N₂ with 58 qubits).

Proof

Run the full regression suite on the engine: integrals and Hartree–Fock against textbook values, CCSD(T) against published references, tapering and ADAPT, the web API against the published study, and the browser engine against the Python engine.

Takes about 3–5 minutes: five suites, including the web API itself.
